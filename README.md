# Note Taking App

A simple note-taking application built with HTML, CSS, and JavaScript. Users can create, edit, and manage notes through an interactive interface.

## Features

- Create new notes
- Edit existing notes
- Save note content dynamically
- Delete notes
- Interactive user interface
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

- DOM manipulation and updating content dynamically
- Working with event listeners and user interactions
- Creating and managing elements with JavaScript
- Using variables to store and update application state
- Working with forms and user input
- Showing, hiding, and updating content based on user actions
- Writing cleaner and more organized JavaScript code
- Debugging and troubleshooting JavaScript logic
